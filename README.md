# ГрузДоставка

Учебный проект по модулям 1–3.

## Запуск
1. Установить XAMPP, запустить Apache + MySQL.
2. Импортировать `backend/database/dump.sql` в базу `gruzdostavka`.
3. Положить проект в `htdocs/gruz/`.
4. Открыть http://localhost/gruz/

## Тестовые аккаунты
- Админ: `Admin` / `GruzDOST`
- Пользователь: регистрируется сам.

## Структура
- `index.php` — главная + слайдер
- `frontend/` — страницы
- `backend/` — классы, действия, БД
